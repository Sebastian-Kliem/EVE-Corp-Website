# ESI API Dokumentation

In diesem Ordner können externe Dokumentationsdateien für die EVE Online ESI API abgelegt werden.

## Empfohlene Dateien
1. **ESI OpenAPI Spezifikation (`swagger.json`):**
   Du kannst die offizielle OpenAPI-Spezifikation (JSON) von CCP herunterladen und hier ablegen:
   - URL: `https://esi.evetech.net/latest/swagger.json`
   - Befehl zum Herunterladen:
     ```bash
     wget https://esi.evetech.net/latest/swagger.json -O docs/esi/swagger.json
     ```

2. **Eigene Notizen & Scopes:**
   Erstelle hier zusätzliche Markdown-Dateien für projektspezifische API-Notizen, genutzte Scopes und Endpunkte.
